# 공프4 기말 시연 영상 촬영 가이드 (최종)

> 최종 발표자료는 `공프4_기말발표_PPT_최종.pptx`이며 영상 자리는 **7장**입니다.

목표: 최종 PPT 7장에 넣을 **약 45초** 화면 녹화 1개. 음성은 녹화하지 않고 발표 중 직접 말합니다(대본 7장).
내용: 실적 입력 → 긴급 판정 → 후보 비교(추가근무 포함) → 승인 → 계획 v2 반영. 시연 화면은 실제로 동작하는 시스템이며, 아래 수치는 자동 테스트(`tests/integration/test_demo_overtime_option.py`)로 고정된 값입니다.

## 1. 준비 (녹화 전 1회, 약 5분)

```bash
cd project4_manufacturing_logic
git pull origin main
python -m pip install -e ".[dev]"

# DB를 중간발표 시작 상태로 초기화 (서버가 꺼진 상태에서)
python -m production_control.demo.init_db --reset

# 터미널 1: API, 추가근무 후보 켜기
PRODUCTION_CONTROL_OVERTIME_END=19:00 \
python -m uvicorn production_control.api.runtime:app --host 127.0.0.1 --port 8000

# 터미널 2: 관리자 화면, 시연 시각 고정 (10/22 13:17)
PRODUCTION_CONTROL_DEMO_TIME=2026-10-22T13:17:00+09:00 \
python -m streamlit run src/production_control/ui/overview.py --server.address 127.0.0.1
```

- 브라우저: `http://127.0.0.1:8501`, 창 너비 1600px 이상, 확대 100%. 사이드바는 접어 두면 화면이 넓어집니다(왼쪽 위 `«`).
- 두 환경변수를 빼먹으면 안 됩니다. `OVERTIME_END`가 없으면 추가근무 후보가 안 나오고, `DEMO_TIME`이 없으면 실제 날짜(11월) 기준이라 모든 LOT가 지연으로 보입니다.
- 다시 찍을 때: 두 서버를 끄고 `init_db --reset`부터 반복합니다(승인 결과가 DB에 남기 때문).

## 2. 녹화 순서와 시간 (총 약 45초)

| 시간 | 화면 | 동작 | 확인할 값 |
|---|---|---|---|
| 0–5초 | 상단 라디오 **생산현황** | 그대로 둠 | 현재 승인 계획 **v1**, 긴급 LOT **0**, 입력 대기 작업 1 |
| 5–15초 | **현장 실적 입력** | LOT `LOT-001`, Unit `U030` 선택 → `예상 잔여 작업시간 입력/수정` 펼침 → 앞으로 더 필요한 작업시간 **480** 입력 → `예상 잔여 작업시간 반영` 클릭 | U030 현재 공정 튜닝, 작업 중 |
| 15–20초 | **생산현황** | 지표 확인 후 간트차트까지 살짝 스크롤 | 긴급 LOT **1** |
| 20–33초 | **재계획** | 빨간 문구 확인 → `재계획안 계산·비교` 클릭 → 순위표로 스크롤 | "LOT-001 생산 완료 예상이 출하검사 시작보다 4시간 57분 늦습니다", 1위 3개(EDD·Slack·CR + 추가근무) **2시간 57분 / 추가 가동 2시간** |
| 33–40초 | 재계획(아래) | 재계획안 간트차트 지나 승인 버튼 `EDD · 납기가 가까운 LOT 우선 + 추가근무(~19:00, 10/22) 재계획안 승인` 클릭 | 초록 안내 "승인 완료 · 새 승인계획 v2" |
| 40–45초 | **생산현황** | 지표 확인 | 현재 승인 계획 **v2**, 긴급 LOT **1** (여전히 긴급) |

순위표는 "공동 1위"로 세 줄이 나옵니다. 어느 것을 골라도 지연은 같고, 대본·PPT는 EDD + 추가근무를 승인하는 것으로 맞춰 두었습니다. 기본 선택은 첫 줄(EDD)입니다. 다른 줄이 선택돼 있으면 순위표 아래 `상세 확인할 재계획안` 상자에서 EDD를 고른 뒤 승인합니다.

## 3. 주의할 점

- 숫자가 위 표와 다르면 DB 초기화나 환경변수를 의심합니다. 승인 후에도 LOT-001은 긴급(177분 지연)으로 남는 것이 정상입니다. "추가근무로 해결됐다"고 말하지 않습니다.
- 마우스는 천천히, 클릭 전 0.5초 멈춤. 계산·승인 직후 화면이 다시 그려지는 1–2초는 자르지 않아도 됩니다.
- 녹화 해상도 1920×1080, 30fps, MP4(H.264). OBS 또는 Windows `Win+Alt+R`, macOS `Cmd+Shift+5`.
- 개인 정보(브라우저 북마크·다른 탭·알림)가 화면에 나오지 않게 전체화면(F11) 권장.

## 4. PPT에 넣기

PowerPoint에서 7장의 재생 아이콘 영역을 지우고 `삽입 → 비디오 → 이 디바이스`로 MP4를 넣은 뒤, `재생 → 시작: 자동 실행`(또는 클릭 시)으로 설정합니다. 영상이 45초를 넘으면 `비디오 트리밍`으로 앞뒤를 자릅니다.
