## 직접 하실 일 (순서대로)

1. **Mac PowerPoint에서 확인 (5분)**: `공프4_기말발표_PPT.pptx`를 열고 `슬라이드 쇼 → 처음부터`로 끝까지 넘겨 봅니다.
   - 모핑이 들어간 장: 2, 8, 9, 10, 13, 18, 20, 23, 25 (도형이 앞 장에서 이어서 움직이면 정상). 나머지는 짧은 페이드.
   - 19→20장(점 810개가 흩어지며 색이 바뀜)이 버벅이면 **백업판** `공프4_기말발표_PPT_백업_점이동없음.pptx`를 대신 씁니다. 내용·노트·장 번호는 같고 그 장면만 제자리 색 변화입니다.
   - 글꼴(Noto Sans CJK KR)이 Mac에 없으면 다른 글꼴로 바뀌어 글이 넘칠 수 있으니 한 번 훑어봅니다.
2. **시연 영상 녹화 후 14장에 삽입**: 가이드대로 녹화(브라우저 탭 3개: 관리자 화면, 작업지시 13:17, 작업지시 17:00) → 14장 회색 상자 자리에 넣고 `재생 → 시작: 자동 실행`.
3. **발표 녹음 = 발표 동영상**: `슬라이드 쇼 → 슬라이드 쇼 녹화(Record)` → 처음부터 대본대로 말하며 클릭으로 넘김 → `파일 → 내보내기 → 동영상(MP4)`. 장마다 클릭 한 번이면 되고, 장 안에서 따로 누를 애니메이션은 없습니다.
4. **제출**: 위 1~4.

예상 시간은 보통 속도(초당 5글자)로 약 9분 31초입니다(영상 60초·전환·장마다 쉼 포함). 빠르게(초당 5.5글자) 읽으면 약 8분 48초입니다. 실제 시간은 녹음 리허설로 확인해 주세요.
